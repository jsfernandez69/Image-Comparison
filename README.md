# Image Comparison

A Streamlit web application that compares two images and computes their Structural Similarity Index (SSIM).

## Features
* **Image Upload:** Upload two images in JPEG or PNG format.
* **Auto-Resizing:** Automatically matches image dimensions for evaluation.
* **SSIM Calculation:** Generates an overall percentage similarity score.
* **Difference Heatmap:** Displays a visual overlay highlighting exact differences between images.
